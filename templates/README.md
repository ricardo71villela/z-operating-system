# Templates

## Purpose
Reusable templates that keep documentation structurally consistent across every domain.

## Scope
- `document-template.md` — generic template for any standalone document.
- `domain-readme-template.md` — template for a top-level domain's `README.md`.

Architecture decisions use `architecture/decision-records/adr-template.md` instead.
