2. O que a app faz com os teus dados

O Z Studio foi construído para guardar o mínimo possível fora do teu dispositivo. Em concreto:

  • Fotos e vídeos que carregas — nunca saem do teu dispositivo. Ficam guardados localmente no teu browser (através de uma tecnologia chamada IndexedDB) e nunca são enviados para nenhum servidor nosso.
  • Textos que escreves (título, preço, localização, características do produto) — também ficam só no teu dispositivo, exceto quando usas explicitamente a funcionalidade "Legenda com IA" ou "Traduzir para todos os idiomas". Nesse caso, esse texto (nunca as fotos) é enviado ao nosso servidor, que o reencaminha para a Anthropic (o fornecedor do modelo de IA que gera a legenda) e devolve o resultado.
  • Definições de marca (nome, cor, logótipo que carregues, site) — guardadas localmente, da mesma forma.

3. Com quem partilhamos dados

  • Anthropic (fornecedor do modelo de IA) — recebe o texto que envias explicitamente para gerar uma legenda. Não recebe fotos. Ver a política de privacidade da Anthropic em anthropic.com/legal/privacy.
  • [FORNECEDOR DE ALOJAMENTO — ex.: Vercel/Netlify] — aloja a aplicação; pode registar informação técnica básica de acesso (endereço IP, data/hora) por razões de segurança.
  • Não vendemos nem partilhamos dados pessoais para fins de publicidade.

4. Pagamentos (se aplicável)

Se subscreveres um plano pago, o processamento do pagamento é feito por [Stripe / outro processador], que trata diretamente os dados do cartão — nunca vemos nem guardamos o número do teu cartão.

5. Quanto tempo guardamos os dados

As fotos, textos e definições de marca ficam guardados no teu dispositivo até os apagares — através do botão "Limpar rascunho" dentro da app, ou ao limpar os dados de navegação do teu browser. Não temos acesso a esses dados e, por isso, não os podemos apagar por ti remotamente.

6. Os teus direitos

Ao abrigo do RGPD, tens direito a:

  • Acesso e portabilidade — os teus dados já estão acessíveis a qualquer momento no teu próprio dispositivo.
  • Apagamento — usa o botão "Limpar rascunho" ou limpa os dados do site no teu browser.
  • Informação — contacta-nos em [EMAIL] para qualquer dúvida.
  • Reclamação — podes apresentar queixa junto da Comissão Nacional de Proteção de Dados (CNPD), em cnpd.pt.
