Politique de confidentialité

Z Studio · Dernière mise à jour : 7 septembre 2026

Pour toute question relative à la confidentialité, contactez hello@zstudio.space.

2. Ce que l'application fait de vos données

Z Studio a été conçu pour conserver le minimum de données en dehors de votre appareil. Concrètement :

  • Photos et vidéos que vous importez — ne quittent jamais votre appareil. Elles sont conservées localement dans votre navigateur (via une technologie appelée IndexedDB) et ne sont jamais transmises à l'un de nos serveurs.
  • Textes que vous saisissez (titre, prix, localisation, caractéristiques du produit) — restent également uniquement sur votre appareil, sauf lorsque vous utilisez explicitement une fonctionnalité d'intelligence artificielle (« Légende IA », « Variantes de ton et hashtags » ou « Traduire dans toutes les langues »). Dans ce cas, ce texte (jamais les photos) est envoyé à notre serveur, qui le retransmet via Vercel AI Gateway à Anthropic (le fournisseur du modèle d'IA qui génère le résultat) et vous renvoie la réponse.
  • Logo que vous importez — conservé localement, de la même manière, et jamais transmis à l'un de nos serveurs.
  • Autres paramètres de marque (kit de marque) — nom, couleur, site web, téléphone, affichage du filigrane, langues actives, et les libellés de catégorie/fiche associés à ce kit — restent conservés localement, et, si vous êtes connecté, également dans notre base de données Supabase, pour continuer à travailler depuis un autre appareil avec les mêmes kits de marque. Sans connexion, ils restent uniquement locaux, comme avant. N'inclut jamais le logo, qui reste toujours uniquement sur l'appareil.
  • Compte et abonnement — si vous créez un compte, nous conservons votre email, un identifiant de compte et l'état de votre abonnement (offre active, dates de renouvellement/expiration, période d'essai en cours) dans une base de données Supabase. Nous ne conservons aucun mot de passe — l'accès se fait par un code envoyé à votre email (OTP). Nous ne conservons pas le jeton d'achat brut Apple/Google/Stripe dans un stockage persistant.

3. Avec qui partageons-nous des données

  • Anthropic (fournisseur du modèle d'IA, via Vercel AI Gateway) — reçoit le texte que vous envoyez explicitement pour générer une légende, des variantes de ton ou une traduction. Ne reçoit jamais de photos. Voir la politique de confidentialité d'Anthropic sur anthropic.com/legal/privacy.
  • Vercel — héberge l'application et le runtime commercial/serveur, et sert d'intermédiaire (AI Gateway) pour les requêtes d'IA ; peut enregistrer des informations techniques d'accès de base (adresse IP, date/heure) à des fins de sécurité. Certains de ces prestataires peuvent traiter des données en dehors de l'Espace économique européen (notamment aux États-Unis) ; dans ce cas, des garanties contractuelles RGPD s'appliquent (clauses contractuelles types).
  • Supabase — conserve le compte, l'état de l'abonnement/droit d'accès, authentifie la connexion par code email et, si vous êtes connecté, les kits de marque (nom, couleur, site, téléphone, catégorie/fiche — jamais le logo).
  • Resend — envoie les emails transactionnels de l'application (par exemple, le code de connexion).
  • Stripe, Apple (App Store/StoreKit) et Google (Play Billing) — traitent le paiement selon la plateforme utilisée. Voir section 4.
  • Nous ne vendons ni ne partageons de données personnelles à des fins publicitaires.

4. Paiements

Si vous souscrivez une offre payante, le paiement est traité par Stripe (Web/Microsoft), par Apple via l'App Store (iOS) ou par Google via Google Play (Android), selon la plateforme utilisée. Ces prestataires traitent directement les données de carte/moyen de paiement — nous ne voyons ni ne conservons jamais votre numéro de carte. Nous recevons uniquement la confirmation de l'abonnement et son statut (actif, en essai, annulé, etc.).

5. Durée de conservation des données

Les photos, le logo et les textes restent sur votre appareil jusqu'à ce que vous les supprimiez — via le bouton « Effacer le brouillon » dans l'application, ou en effaçant les données de navigation de votre navigateur. Nous n'avons pas accès à ces données et ne pouvons donc pas les supprimer à votre place à distance. Les données de compte, d'abonnement et les kits de marque synchronisés (email, statut d'abonnement, kits de marque) sont conservées tant que le compte existe ; sur demande de clôture du compte, nous les supprimons, sauf le minimum que nous serions légalement tenus de conserver (par exemple à des fins fiscales/comptables).

6. Vos droits

En vertu du RGPD, vous disposez des droits suivants :

  • Accès et portabilité — vos données de création sont déjà accessibles à tout moment sur votre propre appareil ; les données de compte peuvent être demandées à hello@zstudio.space.
  • Suppression — utilisez le bouton « Effacer le brouillon » pour les données locales, ou demandez la clôture du compte pour les données d'abonnement.
  • Rectification et opposition — contactez-nous à hello@zstudio.space.
  • Réclamation — Z Studio étant exploité depuis la France, vous pouvez déposer une réclamation auprès de la CNIL (Commission Nationale de l'Informatique et des Libertés), sur cnil.fr, ou auprès de l'autorité de protection des données de votre propre pays de résidence dans l'UE.

7. Mineurs

Z Studio est destiné aux utilisateurs âgés de 18 ans ou plus, ou de l'âge minimum de consentement numérique dans votre pays.

8. Modifications de cette politique

Nous pouvons mettre à jour cette politique. Les modifications importantes seront signalées dans l'application.
