# Decision Records (ADRs)

## Purpose
Chronological, immutable log of significant architectural decisions and the reasoning behind them, so context is never lost as the company grows.

## Scope
Technical and structural decisions with lasting consequences. Not for day-to-day implementation choices — only decisions a future team member would need to understand "why is it built this way."
