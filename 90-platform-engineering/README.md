# Platform Engineering

## Purpose
Defines the engineering standards, conventions, platform/module structure and operational integration rules used across the ZOS monorepo.

## Scope
Engineering standards, coding conventions, technology-stack principles, CI/release authority, shared-infrastructure rules, and how independently owned product modules integrate as one ecosystem.

This repository now contains both architecture/governance material **and operational application code** for the five active products. Platform Engineering defines the mechanisms and integration boundaries; it does not take ownership of each product's vertical semantics.
