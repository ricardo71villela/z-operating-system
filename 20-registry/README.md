# Registry

## Purpose
Defines the canonical layer of identity, relationships and authoritative state for Entities relevant to the Z ecosystem — organizations, companies, brands, products, partners, properties, developments, projects, markets, datasets, and other canonical Entities. Registry is the foundation that Trust Engine, Data, Marketplace and Intelligence all reference for identity; it is not limited to real estate.

## Scope
The Entity model — `Entity → Identity → Relationships → State → History → Provenance` — and the source-of-truth rules for resolving which representation of an Entity is canonical. Does not hold observations, measurements or events *about* those entities — see `60-data` for the formal Registry/Data boundary. Does not define marketplace transaction flow — see `50-marketplace`.
