# Legal and Compliance

## Purpose
Defines the legal and regulatory obligations the ecosystem must uphold — real estate licensing (AMI), data protection law (GDPR/RGPD), and anti-money-laundering (AML/KYC) requirements, with headroom for financial-services regulation as the ecosystem grows.

## Scope
Licensing, data-protection compliance, AML/KYC, contract-law considerations. Does not define technical security controls — see `100-security`.
